03 // Radius + Motion
Sharp Corners, Intentional Motion
The brand system favors sharp corners (max 4px on data surfaces, 8px on modals only). Current app uses 12px base radius. Motion is strictly limited: one auto-animated moment (rating tick), everything else is reactive hover/focus.

Motion rules Only auto-animated moment: rating tick (480ms, ease-out, no bounce). LIVE pulse (1400ms loop) on live indicators. All other transitions are reactive (hover 100ms, fades 240ms). No decorative motion. No spring physics.

10 // Open Decisions
Questions for Review
Items that need your sign-off before implementation begins.
1. Font loading strategy The brand requires 4 Google Fonts (Bebas Neue, DM Sans, Inter, JetBrains Mono). On web this is straightforward (next/font or Google Fonts CDN). On mobile, these need to be bundled as assets or loaded via expo-font. This adds ~200KB to the mobile bundle. Proceed?
2. Shadows: remove entirely? The brand system explicitly forbids drop shadows. The current app uses shadow-card, shadow-glow-primary, and glass effects. Remove all shadows and rely purely on background-color shifts for depth, per the brand spec?
3. Radius: go fully sharp? Current app uses 12px base radius everywhere. Brand spec says 4px max (8px for modals only). This is the most visually dramatic change. Some rounded pill badges and fully-rounded avatars will look very different. Apply universally, or keep avatar circles?
4. Light mode: Paddock or keep current? The CEO's Paddock palette has no pure white, surfaces darken as they elevate. This is intentionally different from typical light themes. Current light mode uses white cards on light gray bg. Adopt Paddock as-is, or soften it (e.g. keep some white)?
5. Nav rename: "Rankings" to "Ladder"? The brand uses "Ladder" consistently for the leaderboard/rankings. The bottom nav tab currently says "Rankings". Rename to "Ladder"?
6. Rating tick animation The brand specifies a signature animation: old rating slides out (240ms), new rating slides in (480ms total), with a color flash (green/red for 240ms, then settle to white). This is the only auto-animated moment. Implement as part of this rebrand, or defer?
7. "Beta" badge styling Currently shows "JITS Beta" (now "ELO RATED Beta") in muted text. The brand has a specific badge pattern (JetBrains Mono, padded, bordered). Apply the branded badge style?
