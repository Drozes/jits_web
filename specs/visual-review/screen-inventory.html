Join Wizard

Multi-step wizard to join a session lobby. Steps are dynamic: geo check is skipped if gym has no coordinates; waiver step is skipped if already signed or not required.

Uses browser geolocation API. Haversine distance check (2km threshold). Four states: checking (spinner), success (green check), far (amber warning, can still continue), denied/failed (can still continue). Step is skipped entirely if gym has no lat/lng.
